# data/

Gitignored. Nothing in this directory is ever committed except this file
(README section 9).

Datasets and generated splits live here and are recreated from a committed
script and a seed, so the same split can be reproduced by anyone without
committing gigabytes to git.

Before a dataset is used anywhere, record its licence in
[DATA_LICENSES.md](../docs/DATA_LICENSES.md).
